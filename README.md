# Chrome-расширение: Экспорт заказов в CSV

Chrome-расширение для автоматического сбора таблицы заказов с веб-страницы и выгрузки её в стандартизированный файл `.csv` строго по техническому заданию.


## Установка и запуск

1. Скачайте проект в виде ZIP-архива и распакуйте его в папку на компьютере (или клонируйте репозиторий).
2. Откройте браузер Google Chrome и перейдите по адресу: `chrome://extensions/`
3. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с проектом.

---

## Использование

1. Откройте страницу с таблицей заказов.
2. Нажмите на иконку расширения на панели браузера.
3. Во всплывающем окне нажмите кнопку **«Скачать CSV»**, дождитесь конца работы расширения и выберите место сохранения файла.
4. Дождитесь завершения загрузки и откройте полученный `.csv` файл в блокноте или Microsoft Excel.
